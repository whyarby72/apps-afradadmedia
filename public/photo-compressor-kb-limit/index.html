Questions before you use it

Does the app upload my photo for compression?

No. The core compression code processes the selected JPEG on your device and does not upload it to an Afradad Media server for compression.

Does it overwrite the original?

No. The normal workflow preserves the source photo and creates a separate result you can save or share.

What if I do not know the upload limit?

Use the smaller-copy path. The result is treated as reduced rather than verified against a limit you did not provide.

What image formats are supported?

The current product scope supports JPEG/JPG input.

Does the app require internet access for compression?

The core photo-compression workflow can run locally. Advertising and consent services in an ad-enabled release can require network access.

Do I need an account?

No account or login is required for the core compression workflow.
